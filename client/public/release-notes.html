Release Notes

What's shipped, in the order it shipped — newest first. This is a hobby project built for a small group of friends, so "releases" just means "pushed to the live site," not a formal version scheme.

Curious what's implemented from the rulebook vs. not yet? See Rules Coverage.

August 15, 2026

  • New
    Contacts, in both build systems
    Add contacts and raise their Connection/Loyalty ratings right in the builder. Priority System uses the book's Charisma × 6 point pool (no rating above Charisma). Life Path draws points from your chosen life modules plus Coming of Age instead - Charisma doesn't limit it at all, matching the book's explicit callout that these are genuinely different rules. Life Path contacts can also be pushed further with customization Karma, capped at Charisma.
  • New
    Knowledge & Language skills, in both build systems
    Priority System gets a picker for the first time: a free pool equal to your Logic, spent on knowledge topics or language levels (Basic/Specialist/Expert). Life Path's per-module knowledge picks now support the same language leveling - pick "Sperethiel" from two different modules and it becomes one Sperethiel entry at a higher level instead of two separate ones. Every character also gets one free Native language, tracked separately from either budget.
  • Fix
    Knowledge/Language free allotment was documented wrong
    The Rules Coverage page said Priority System's free Knowledge/Language count was a "Logic+Intuition" budget - the book actually says Logic alone (Logic+Intuition is Memory, an unrelated test). Corrected; the new picker uses the right number.

August 14, 2026

  • New
    Matrix Security NPCs added to import
    4 more Hack & Slash stat blocks: Security Spider, Security Spider Lieutenant, Lesser DemiGOD, and GOD Operative - Matrix defenders with both a body to shoot and a persona to hack.
  • New
    Matrix-native critters added to NPC import
    26 Hack & Slash stat blocks now importable: protosapients (digital predators like the Daemon and Cyberwerewolf), the Null Sect's xenosapients, and Technocritters (Emerged animals with a Matrix persona of their own).
  • New
    Body Shop critters added to NPC import
    31 more stat blocks: everyday animals, 13 named corp-engineered critters (Ares Warhound, MCT HK-Jaws, and more), and 6 resurrected dinosaurs.
  • New
    NPC book-import list grouped by sourcebook, with search
    The "Import from book" list now groups by which book each stat block comes from, and you can type to search across every entry by name or description instead of scrolling an ever-growing list.
  • Fix
    New NPCs got lost below a long import list
    Adding an NPC, whether typed in by hand or imported from the book catalog, now scrolls the page straight to it instead of leaving you to hunt for it. Each NPC also got an explicit Minimize/Expand button.
  • New
    Feature Request/Bug link now opens an email
    The nav bar's request link no longer requires a GitHub account - it opens an email instead, and is relabeled "Feature Request/Bug" to make clear it covers both.
  • New
    Release Notes page
    A running, plain-language changelog - this page - separate from the more technical Rules Coverage reference.
  • New
    Skill Specializations & Expertise
    Buy a specialization on a skill (one per skill point at character creation, or 5 Karma during play), upgrade it to an Expertise once the skill hits rank 5, then add a second specialization on top - matches the book's rules exactly, including the two build systems' genuinely different chargen caps.
  • Fix
    Skill Karma cost was wrong
    Raising a skill during play was charging new-rank×2 Karma; the book prices it the same as attributes, new-rank×5. Corrected - if you'd already raised a skill under the old price, that purchase is left alone, only future ones use the right number.
  • New
    Rules Coverage page
    A standing reference cross-checking the core rulebook's table of contents against what this app actually implements - what's done, what's partial, what's not built yet, and why.
  • New
    Conjuring: summon, bind, and track spirits
    All six core spirit types (Air, Beasts, Earth, Fire, Kin, Water), each with Force-scaled stats computed live, plus a glossary of every power a spirit can carry. Track services owed and Condition Monitor damage while a spirit is bound.
  • New
    Initiation & Submersion Grade tracking
    Raise your Initiate or Submersion Grade during play at the book's real Karma cost, which lifts Magic or Resonance's natural maximum - unlocking further Magic/Resonance advancement that was previously capped.
  • New
    In-play Karma advancement
    Once a character is marked In Play: log Karma and Nuyen earned from a run, spend Karma to raise attributes and skills, and pick up new gear either bought with earned nuyen or looted for free - all itemized with an undo.
