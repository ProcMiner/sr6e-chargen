SR6e CharGen — internal reference

Rules Coverage

Every character-generator-relevant section of the SR6E core rulebook, in the book's own table-of-contents order, with sourcebook additions folded into the matching heading. Scoped to what a character generator needs to build and manage a PC — not combat/Matrix/rigging action resolution, GM advice, or setting lore, which this app was never meant to simulate.

How to read this: statuses reflect the codebase as of today, checked directly against the source files and, in a few spots, freshly verified rather than assumed from older project notes. This page is kept current — updated in the same pass as any rules feature that ships or gap that closes, not as a one-time snapshot.

    Character Creation

    core p. 58

    The step-by-step build flow itself. "Define Your Role and History" and its narrative prompts (birthplace, upbringing, worldview) have no mechanical output to build, and are the same territory the Life Path system covers structurally — not itemized separately below.

    • Done

    Finishing Steps

    • Missing
      Contactsp. 66
      The Contact {name, connection, loyalty} data shape exists, but there's no UI to spend connection/loyalty points against a contact-points budget. Also blocks Coming of Age's own 1-contact starting grant, which currently isn't tracked anywhere.
    • Partial
      Knowledge and Language Skillsp. 67
      Life Path grants and tracks them via module choices. Priority System has no equivalent anywhere — no Logic+Intuition point budget, no picker of any kind. A Priority-built character today has no way to add a single knowledge or language skill in the builder.
    • Done
      Final Calculationsp. 67
      Physical/Stun Monitor, Initiative, Initiative Dice, Attack Rating, Defense Rating all derived live from attributes/gear/adept powers.

    Character Advancement

    • Done
      Post-creation Karma spendp. 68, "Improvement Cost" table p. 71
      Built as an in-play feature, not chargen-time: attributes and skills raised via an itemized, undoable log, both at new-rating×5 Karma (skills previously charged new-rating×2, an unverified guess from before this app had direct rulebook-PDF access - corrected once the actual table confirmed both rows use the same formula). See Post-Creation Advancement below for the full picture, including Initiation/Submersion.
    • Done
      Specializations & Expertisep. 92, 68-69
      One specialization per skill point at chargen (Priority: one per skill; Life Path has no equivalent skill-point pool of its own to spend this way, see Skills below), 5 Karma each in play. Expertise (upgrades +2 to +3) needs an existing specialization and skill rank 5+, post-creation only; a skill can then take a second specialization, capped at 1 expertise + 1 specialization per skill forever, matching the book exactly.
    • Missing
      Priority System power-level variantsp. 63 sidebar
      Street-level (apply one Priority row lower than chosen) and Prime Runner (double starting Karma to 100) aren't offered anywhere.

    Magic

    core p. 126

    Magic Basics

    • Done
      Traditions, Drain resistance, Magical Lodges (as gear)p. 127–129
      Traditions are chosen implicitly via magicOption/awakenedType; Drain formulas referenced throughout Spells/Conjuring; Magical Lodge Materials purchasable as gear.

    Spells

    • Done
      Spell catalogpp. 130–142; Street Wyrd pp. 25–43, 51–53
      140 entries (73 core + 67 Street Wyrd). Free allotment = Magic (Priority-table base) ×2 for Priority-built Full/Aspected/Mystic Adept magicians; every spell beyond costs 5 Karma from the shared pool. Life Path gets 0 free — no equivalent grant text exists for it.

    Ritual Spellcasting & Rituals

    • Missing
      Ritualspp. 143–146 (Circle of Healing, Curse, Prodigal Spell, Ward, Watcher, etc.)
      A structurally different multi-participant, multi-step casting system with its own named catalog — the Magic×2 "spells or rituals" choice is modeled as spells-only.

    Conjuring

    • Done
      Spirits — summon, bind, trackpp. 146–149
      All six core spirit types (Air, Beasts, Earth, Fire, Kin, Water) with Force-scaled attributes/Defense/Initiative/Condition Monitor/attacks, plus a 23-entry Powers glossary. Built as an in-play feature (bound spirits are session-transient, not permanent build data). Summoning/Banishing dice tests stay reference formulas — this app never simulates dice rolls anywhere.
    • Missing
      Street Wyrd's expanded spirit contentStreet Wyrd "A Congress of Spirits," pp. 54–71
      Plant/Guardian/Guidance/Task Spirits, Free Spirits, Ally Spirits, Great Form Spirits — not read yet.

    Enchanting

    • Done
      Foci, Formulae, Reagents, Magical Supplies (as gear)pp. 149–155, 294–295
      All 7 focus types, per-focus formulas, reagents — purchasable and Karma-bondable.
    • Missing
      Alchemy (Preparations) & Artificing (making foci)pp. 149–153
      The crafting processes — not modeled, consistent with this app treating all gear as bought outright rather than simulating any crafting system, magical or otherwise.

    Adepts

    • Done
      Power Points & Adept Powers catalogpp. 156–158; Street Wyrd pp. 77–84
      67 entries (23 core + 44 Street Wyrd). Power Point pool tracks current effective Magic (Essence-capped), not a frozen base — matches the book's "gain/lose a point with Magic" text exactly.
    • Partial
      Adept Ways and Their BenefitsStreet Wyrd pp. 76–77
      Modeled as a single lightweight quality (pick your Way via notes, effect text points to the book) rather than mechanically simulating each of the 9 Ways.
    • Missing
      Adept MetamagicsStreet Wyrd pp. 84–85 (Animal Attunement, Astral Projection, Finding Your Way, Infusion, Item Attunement, Virtuoso)
      Require Initiation — see Initiation & Metamagics below.

    Mystic Adepts & Aspected Magicians

    • Done
      Magic split between spells and Power Pointspp. 158–159
      Mystic Adepts get a dedicated allocation field; free-spell allotment correctly computes off the mage-dedicated remainder, not full Magic.

    The Astral Plane

    • Partial
      Assensing, Astral Projection, Astral Combat, Astral Tracking, Mana Barrierspp. 159–161
      Only the pieces needed elsewhere exist: an Astral Initiative formula (used by Spirits) and "Astral Perception" as a purchasable Adept Power. No actual astral-plane mechanics are simulated.

    Mentor Spirits

    • Partial
      Mentor Spirit qualitypp. 162–166
      Purchasable as a single quality (choose your mentor via notes); the specific bonus/tenet text for each of the printed archetypes isn't individually modeled, effect text points to the book.

    Initiation & Metamagics

    • Done
      Initiate Gradep. 166
      In-play feature: 10+desired-grade Karma cost (confirmed from the book, not guessed), gated on Magic rating, raises Magic's natural maximum.
    • Missing
      Metamagics catalogp. 167
      Grade purchase takes a freeform metamagic name today (same "pick via notes" precedent as Mentor Spirits); the named metamagics themselves (Centering, Masking, Flexible Signature, etc.) aren't a real catalog with mechanical effects yet.
    • Missing
      Initiation/Submersion at chargen ("experienced" character creation)
      Grade tracking only exists in-play; nothing lets a new character start with a Grade already earned.

    Matrix — Technomancers

    core p. 187

    Only the Technomancer build content is in scope here — Matrix Actions, Hosts, IC, and Programs are hacking-action resolution rules for the whole party (mage or not), not character-build data, and this app doesn't simulate dice-rolled tests anywhere.

    • Done
      Living Personap. 189
      Matrix attributes from Charisma/Intuition/Logic/Willpower plus a Resonance-sized bonus pool, each capped at 50% of base (min +4). Tracks current effective Resonance, same convention as Adept Power Points.
    • Done
      Complex Forms catalogpp. 189–191; Hack & Slash pp. 62–67
      39 entries (15 core + 24 Hack & Slash). Free allotment = Resonance (Priority base) ×2; every one beyond costs 5 Karma, same shared pool as Spells.
    • Missing
      Sprites — compile, register, decompilepp. 191–195
      The Resonance-side mirror of Spirit summoning; no in-play tracking or type/power catalog exists.
    • Done
      Submersion Gradep. 195
      Same mechanic and Karma formula as Initiation, mirrored onto Resonance.
    • Missing
      Echoes catalogp. 195
      Same status as Metamagics — Grade purchase takes a freeform name, no mechanical catalog yet.
    • Partial
      Resonant StreamsHack & Slash pp. 130–132
      Modeled as a single lightweight quality unlocking the stream's complex form; the fixed per-stream benefits and each stream's unique Aspect Peripheral power aren't individually mechanized.

    Elsewhere in the App

    • Done
      Character sheet export
      Fills the official Genesis sheet template, pages 1–2, via coordinate overlay. Pages 3–6 (Spells/Adept Powers/Foci/Rituals/Astral Combat) deferred.
    • Out of scope
      NPC roster (Grunts, Critters)core rulebook pp. 203–220; Body Shop pp. 156–165
      A GM-facing bonus feature (70 importable stat blocks across 2 sourcebooks: Core Rulebook, Body Shop), not player character generation — noted here for completeness, not tracked against this audit's pass/fail.
    • Missing
      Reputation & Heat, Run Compensation as tracked stats"Running the Game," pp. 232–243
      No Reputation or Heat field exists anywhere in the character data model. Karma/Nuyen awards cover the practical effect of Run Compensation informally, but the book's own tracked numbers aren't modeled.
    Deliberately not audited line-by-line: Game Concepts' test mechanics, the Combat chapter's process/options/barriers/explosives, the Matrix chapter's individual hacking actions and Host/IC rules, the Rigging chapter's driving/crash/vehicle-combat tests, and the Running the Game chapter's GM advice. None of it is character-build data — it's dice-resolution and GM-facing content a character sheet tool was never meant to simulate, and this app doesn't roll dice anywhere in its own right (damage, Edge, and Karma are always player-reported from the table, never generated by the app).
