SR6e CharGen — internal reference

Rules Coverage

Every character-generator-relevant section of the SR6E core rulebook, in the book's own table-of-contents order, with sourcebook additions folded into the matching heading. Scoped to what a character generator needs to build and manage a PC — not combat/Matrix/rigging action resolution, GM advice, or setting lore, which this app was never meant to simulate.

How to read this: statuses reflect the codebase as of today, checked directly against the source files and, in a few spots, freshly verified rather than assumed from older project notes. This page is kept current — updated in the same pass as any rules feature that ships or gap that closes, not as a one-time snapshot.

    Finishing Steps

    • Done
      Contactsp. 66-67; Companion p. 31
      Priority/Point Buy: Charisma x 6 points spent on Connection + Loyalty, no rating above Charisma. Life Path: points come entirely from selected life modules + Coming of Age's fixed 4 (not from Charisma), rating cap of 8, plus an optional customization-Karma-funded path (1 Karma/point, capped at Charisma). One narrower book rule not enforced: Life Path restricts each module's points to that module's own contact-type list; this app pools all granted points together instead, so players self-adjudicate type matches.
    • Done
      Knowledge and Language Skillsp. 67, 97-99; Companion p. 31
      Corrected from an earlier note that wrongly cited a "Logic+Intuition" budget - it's Logic alone (Logic+Intuition is Memory, an unrelated attribute-only test). Priority/Point Buy: free pool of Logic slots, each spent on a knowledge topic or one level of a language (Basic/Specialist/Expert - Native is always free and separate). Life Path: knowledge/language skills come entirely from life module choices instead, matching each module's own knowledge/language split, with repeated language names leveling up rather than duplicating. Both systems grant one free Native language outside any budget. Deferred: post-chargen ("career mode") purchases of new Knowledge/Language skills, 3 Karma each (p. 71) - not built into LivePlay/Advancement yet.
    • Done
      Final Calculationsp. 67
      Physical/Stun Monitor, Initiative, Initiative Dice, unarmed Attack Rating, and Defense Rating all derived live from attributes/gear/adept powers - see Combat below for the formulas.

    Character Advancement

    • Done
      Post-creation Karma spendp. 68, "Improvement Cost" table p. 71
      Built as an in-play feature, not chargen-time: attributes and skills raised via an itemized, undoable log, both at new-rating×5 Karma (skills previously charged new-rating×2, an unverified guess from before this app had direct rulebook-PDF access - corrected once the actual table confirmed both rows use the same formula). See Post-Creation Advancement below for the full picture, including Initiation/Submersion.
    • Done
      Specializations & Expertisep. 92, 68-69
      One specialization per skill point at chargen (Priority: one per skill; Life Path has no equivalent skill-point pool of its own to spend this way, see Skills below), 5 Karma each in play. Expertise (upgrades +2 to +3) needs an existing specialization and skill rank 5+, post-creation only; a skill can then take a second specialization, capped at 1 expertise + 1 specialization per skill forever, matching the book exactly.
    • Done
      Priority System power-level variantsp. 63 sidebar
      Optional toggle above the Priority Assignment table. Street-level: every category's table values (metatype options, attribute/skill points, magic options, resources) are read one row worse than the letter assigned - floored at row E, exactly as the book describes ("since you can't go any lower than row E, that means you would have two selections from that row"). Prime Runner: doubles the customization Karma pool from 50 to 100. Priority System only, matching where the sidebar sits in the book.

    Combat

    core pp. 67, 104-111

    Mundane (non-Matrix, non-Astral) combat - Attack Rating and Defense Rating are real computed numbers; everything else is reference text, same "no dice-rolling engine" treatment as every other combat-adjacent system in this app.

    • Done
      Attack Rating & Defense Ratingpp. 67, 108
      New "Combat" panel in LivePlay (and a Derived-stats line in the chargen Summary): unarmed Attack Rating (Strength + Reaction) computed live; Defense Rating (Body + worn armor + augmentation armor) computed live too. Worn armor sums your single best owned Clothes/Armor item (base suits "are not cumulative" per the book) plus every Helmet/Shield you own (those do stack) - closes the "no Defense Rating anywhere" and "worn-armor summing deferred" gaps noted in earlier sessions. A melee weapon's own Attack Rating (add Strength directly) and a ranged weapon's printed Attack Rating/Range table stay reference text, since those live as free-text per-item stats in the gear catalog, not a single number to compute against.
    • Done
      Combat Process, Edge in Combat, Range Categories, Firing Modes, Damage Types, Combat Optionspp. 104-111
      Reference tables/text in the same LivePlay panel: the 5-step Combat Process (incl. the Attack/Defense Rating +/-4 Edge-distribution rule) and the Initiative tie-break order (Edge, Reaction, Intuition, coin flip - "ERIC"); the combat-specific Edge spend table (1-5 Edge); the 5 range bands and 4 firing-mode Attack Rating/Damage modifiers; the 4 elemental Damage Types' secondary status effects; and brief reference summaries of Off-Hand Attacks, Knockdown, Multiple Attacks, Grapple, Cover, and Barriers.
    • Missing
      Generic Edge Actions catalogp. 47
      The full 1-5 Edge "Edge Actions" list (Called Shot - Disarm/Vitals, Fire from Cover, Knockout Blow, Bring the Drama, etc.) spans every discipline, not just combat - only the short combat-specific Edge-spend table (reroll/heal/auto-hit/etc.) is transcribed above. A real future chunk, not attempted here.
    • Missing
      Barrier-breaking-through math, Environment/Visibility modifierspp. 111, 118
      Deep GM-facing minutiae (hole diameters by weapon/DV, lighting/weather Edge calls) - same category of content as Hosts/IC for the Matrix chapter, deliberately out of scope.
